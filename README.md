\# DA Statistics – Learning and Practice



\## Project Overview

This repository contains my Statistics learning journey as part of my Data Analytics preparation. It includes class notes, practical exercises, numerical calculations, and Python implementations of statistical concepts.



\## Topics Covered



\### 1. Fundamentals of Statistics

\- Types of Data

\- Population and Sample

\- Descriptive and Inferential Statistics

\- Sampling and Sampling Bias



\### 2. Measures of Central Tendency

\- Mean

\- Median

\- Mode



\### 3. Measures of Dispersion

\- Range

\- Variance

\- Standard Deviation

\- Quartiles

\- Interquartile Range (IQR)

\- Outlier Detection



\### 4. Statistical Relationships

\- Covariance

\- Pearson Correlation

\- Spearman Correlation

\- Positive and Negative Correlation

\- Linear and Non-linear Relationships



\### 5. Probability and Distributions

\- Probability Concepts

\- Bernoulli Distribution

\- Binomial Distribution

\- Poisson Distribution

\- Normal Distribution

\- Uniform Distribution

\- PMF, PDF and CDF



\### 6. Data Visualization

\- Scatter Plots

\- Box and Whisker Plots

\- Outlier Visualization



\## Technologies Used

\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- SciPy

\- Jupyter Notebook
